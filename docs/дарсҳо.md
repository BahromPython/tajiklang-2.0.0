# TajikLang — Дарсҳо

Сездаҳ дарс барои оғози барномасозӣ. Ҳеҷ донише лозим нест — на аз забони
англисӣ, на аз барномасозӣ.

Барои иҷрои барномаҳо файли `playground/index.html` -ро дар браузер кушоед.
Он ҳама чизи заруриро дар худ дорад.

**Тартиби кор:** ҳар дарсро хонед, мисолро худатон нависед (нусхабардорӣ
накунед — нависед), иҷро кунед, баъд машқро иҷро кунед. Агар хато шавад,
хатогиро бо диққат хонед: он ба шумо мегӯяд, ки чӣ бояд кард.

---

## Дарси 1 — Аввалин барнома

Барнома маҷмӯи фармонҳост. Компютер онҳоро аз боло ба поён иҷро мекунад.

Аввалин фармони мо — **`навис`**. Он ҳар чизеро, ки ба ӯ диҳед, чоп мекунад.

```
навис("Салом Тоҷикистон!")
```

Натиҷа:

```
Салом Тоҷикистон!
```

Диққат диҳед:

- `навис` — номи фармон;
- қавсҳо `( )` — дохили онҳо чизе, ки чоп мешавад;
- нохунакҳо `" "` — нишон медиҳанд, ки ин **матн** аст.

`навис` метавонад якчанд қиматро якбора чоп кунад, бо вергул ҷудо:

```
навис("Салом", "Тоҷикистон", 2026)
```

Барои худатон ёддошт гузоштан аломати `#` истифода баред. Ҳар чизе, ки баъд
аз `#` меояд, иҷро намешавад:

```
# Ин шарҳ аст — компютер онро намебинад
навис("Ин иҷро мешавад")
```

**Машқ 1.**
1. Барномае нависед, ки номи шумо ва номи шаҳри шуморо чоп кунад.
2. Се сатр чоп кунед: салом, ном, хайр.
3. Нохунакро дар як ҷой нест кунед ва хатогиро хонед. Чӣ мегӯяд?

## Дарси 2 — Тағйирёбандаҳо

Тағйирёбанда — ин ном барои як қимат аст. Мисли қуттие, ки ба он ном
гузоштаед.

Барои сохтани тағйирёбандаи нав калимаи **`бигзор`** -ро истифода мебарем:

```
бигзор ном = "Баҳром"
бигзор синну_сол = 16

навис("Салом,", ном)
навис("Синну сол:", синну_сол)
```

Барои **иваз кардани** қимати тағйирёбандае, ки аллакай ҳаст, `бигзор`
**нанависед**:

```
бигзор ҳисоб = 0
ҳисоб = 5          # иваз шуд
ҳисоб = ҳисоб + 1  # акнун 6
навис(ҳисоб)
```

Чаро ин ду амали ҷудогона аст? Барои он ки хатои имлоӣ пинҳон намонад. Агар
шумо номро нодуруст нависед:

```
бигзор ном = "Баҳром"
нмо = "Далер"
```

забон мегӯяд:

```
Номи "нмо" муайян нашудааст.
Маслиҳат: Аввал онро эълон кунед: бигзор нмо = ...
```

Дар бисёр забонҳо ин хато пинҳон мемонад ва барнома нодуруст кор мекунад.

Номи тағйирёбанда метавонад пурра тоҷикӣ бошад: `ҳарорат`, `шаҳр`,
`синну_сол`, `қимат`. Дар байни калимаҳо аломати `_` гузоред, на холигӣ.

**Машқ 2.**
1. Се тағйирёбанда созед: ном, синну сол, шаҳр. Ҳамаро чоп кунед.
2. Синну солро як зиёд кунед ва аз нав чоп кунед.
3. `бигзор ном = "..."` -ро ду маротиба нависед. Чӣ мешавад? Чаро?

## Дарси 3 — Ҳисоб

TajikLang бо рақамҳо кор мекунад. Амалҳо ҳамон тавре, ки дар математика:

```
+   ҷамъ
-   тарҳ
*   зарб
/   тақсим
%   боқимонда
```

```
бигзор паҳно = 4
бигзор дарозии_тахта = 7.5

навис("Масоҳат:", паҳно * дарозии_тахта)
навис("Нисфи он:", паҳно * дарозии_тахта / 2)
навис("Боқимондаи 10 ба 3:", 10 % 3)
```

**Тартиби амалҳо** ҳамон аст, ки дар мактаб: аввал зарб ва тақсим, баъд ҷамъ
ва тарҳ. Барои тағйир додани тартиб қавс гузоред:

```
навис(2 + 3 * 4)      # 14
навис((2 + 3) * 4)    # 20
```

Аломати `+` барои матн низ кор мекунад — онҳоро мепайвандад:

```
навис("Салом " + "Баҳром")
```

Вале матн ва рақамро бо `+` пайваст кардан **мумкин нест**:

```
навис("Синну сол: " + 16)
```

```
Амали "+" байни матн ва рақам иҷро намешавад.
Маслиҳат: Ҳарду бояд рақам бошанд, ё ҳарду матн.
```

Ду роҳи дуруст:

```
навис("Синну сол:", 16)              # вергул
навис("Синну сол: " + ба_матн(16))   # табдил
```

**Машқ 3.**
1. Масоҳат ва периметри росткунҷаро ҳисоб кунед.
2. Ҳарорати Селсийро ба Фаренгейт табдил диҳед: `Ф = С * 9 / 5 + 32`.
3. `навис(1 / 0)` -ро иҷро кунед. Хатогӣ чӣ мегӯяд?

## Дарси 4 — Маълумот гирифтан аз корбар

То ҳол барномаҳои мо ҳамеша як хел кор мекарданд. Акнун бигзор онҳо савол
диҳанд.

Фармони **`хонед`** аз корбар як сатр мегирад:

```
бигзор ном = хонед("Номи шумо чист? ")
навис("Салом,", ном)
```

**Муҳим:** `хонед` ҳамеша **матн** бармегардонад, ҳатто агар корбар рақам
нависад. Барои табдил ба рақам `ба_рақам` -ро истифода баред:

```
бигзор ҷавоб = хонед("Синну соли шумо: ")
бигзор сол = ба_рақам(ҷавоб)
навис("Соли оянда шумо", сол + 1, "мешавед")
```

Агар корбар ба ҷои рақам матн нависад, `ба_рақам` хато медиҳад. Инро дар
дарси 5 санҷида метавонем.

**Машқ 4.**
1. Ном ва шаҳрро пурсед, баъд салом гӯед.
2. Ду рақам пурсед ва ҷамъ, тарҳ, зарб ва тақсими онҳоро чоп кунед.
3. Соли таваллудро пурсед ва синну солро ҳисоб кунед.

## Дарси 5 — Муқоиса ва шартҳо

Барномаи ҳақиқӣ бояд **қарор қабул кунад**.

Аввал муқоиса. Натиҷаи ҳар муқоиса ё **`рост`** аст, ё **`дурӯғ`**:

```
==   баробар аст
!=   баробар нест
>    калон
<    хурд
>=   калон ё баробар
<=   хурд ё баробар
```

```
навис(16 >= 16)     # рост
навис(16 > 16)      # дурӯғ
```

Акнун шарт. Калимаи **`агар`** амалҳоро танҳо дар ҳолати дуруст иҷро мекунад:

```
бигзор синну_сол = 16

агар синну_сол >= 18:
    навис("Шумо калонсол ҳастед")
вагарна агар синну_сол >= 16:
    навис("Шумо наврас ҳастед")
вагарна:
    навис("Шумо ҳанӯз хурд ҳастед")
```

Ду чизи муҳим:

1. Баъд аз шарт аломати **`:`** гузоред.
2. Сатрҳои дохилӣ бо **4 холигӣ** сар мешаванд. Ин холигиҳо маънӣ доранд —
   онҳо нишон медиҳанд, ки кадом амалҳо дохили шарт ҳастанд.

Шартҳоро бо **`ва`**, **`ё`**, **`не`** якҷоя кардан мумкин аст:

```
агар синну_сол > 10 ва синну_сол < 20:
    навис("Байни 10 ва 20")

агар не (синну_сол == 16):
    навис("16 нест")
```

**Диққат:** дар TajikLang шарт бояд ҳатман муқоиса бошад. Ин хато аст:

```
агар ном:
```

```
Шарти "агар" қимати мантиқӣ мехоҳад, вале матн гирифт.
```

Дуруст:

```
агар ном != "":
```

**Машқ 5.**
1. Рақам пурсед ва бигӯед, ки он мусбат, манфӣ ё сифр аст.
2. Синну сол пурсед ва бигӯед, ки шахс ба мактаб меравад ё не.
3. Се баҳо пурсед ва миёнаро ҳисоб карда, «аъло», «хуб» ё «қаноатбахш»
   гӯед.

## Дарси 6 — Даврҳо

Агар шумо хоҳед, ки як амал якчанд маротиба такрор шавад, давр созед.

**`барои`** барои шумурдан:

```
барои i аз 1 то 5:
    навис(i)
```

Натиҷа: `1 2 3 4 5` — ҳарду ҳадд дохил мешаванд. `аз 1 то 5` маҳз аз 1 то 5
аст, на то 4.

Ҳисоби ҷамъи рақамҳо:

```
бигзор ҷамъ = 0
барои i аз 1 то 10:
    ҷамъ = ҷамъ + i
навис("Ҷамъ:", ҷамъ)
```

**`то_вақте`** то он даме кор мекунад, ки шарт дуруст аст:

```
бигзор ҳисоб = 1
то_вақте ҳисоб <= 3:
    навис("Такрори", ҳисоб)
    ҳисоб = ҳисоб + 1
```

**Эҳтиёт:** агар шумо `ҳисоб = ҳисоб + 1` -ро фаромӯш кунед, давр ҳеҷ гоҳ
хотима намеёбад. TajikLang инро мефаҳмад ва барномаро бо хатогӣ нигоҳ
медорад — браузери шумо кор карданро бас намекунад.

Даврҳоро дохили ҳамдигар гузоштан мумкин аст:

```
барои сатр аз 1 то 3:
    барои сутун аз 1 то 3:
        навис(сатр, "x", сутун, "=", сатр * сутун)
```

**Машқ 6.**
1. Рақамҳои аз 1 то 20 -ро чоп кунед, вале танҳо ҷуфтҳоро (`i % 2 == 0`).
2. Ҷадвали зарби рақами интихобкардаи корбарро чоп кунед.
3. Аз 10 то 1 ба поён ҳисоб кунед, баъд «Оғоз!» гӯед.

## Дарси 7 — Функсияҳо

Функсия — ин номи як гурӯҳ амал. Онро як маротиба менависед ва ҳар қадар
хоҳед даъват мекунед.

```
функсия ҷамъи_ду(a, b):
    баргардон a + b

навис(ҷамъи_ду(5, 7))
```

- `функсия` — эълони функсия;
- `a` ва `b` — **параметрҳо**, қиматҳое, ки функсия мегирад;
- `баргардон` — натиҷаро бармегардонад.

Функсия метавонад чизе барнагардонад, танҳо кореро иҷро кунад:

```
функсия хуш_омадед(ном):
    навис("=========")
    навис("Салом,", ном)
    навис("=========")

хуш_омадед("Баҳром")
```

Функсия метавонад худашро даъват кунад. Ин **рекурсия** ном дорад:

```
функсия факториал(n):
    агар n <= 1:
        баргардон 1
    баргардон n * факториал(n - 1)

навис(факториал(5))   # 120
```

Ҳар функсияи рекурсивӣ бояд **ҳолати хотима** дошта бошад — дар мисоли боло
ин `агар n <= 1` аст. Бе он давр беохир мешавад.

Тағйирёбандаҳои дохили функсия берун аз он дида намешаванд:

```
функсия санҷиш():
    бигзор пинҳон = 1

санҷиш()
навис(пинҳон)     # ХАТО
```

Ин хуб аст: ҳар функсия ҷаҳони худро дорад.

**Машқ 7.**
1. Функсияи `майдон(дарозӣ, паҳно)` нависед.
2. Функсияе нависед, ки бигӯяд рақам ҷуфт аст ё тоқ.
3. Функсияи рекурсивии `ҷамъи_то(n)` нависед, ки ҷамъи 1 то n -ро ҳисоб
   кунад.

## Дарси 8 — Рӯйхатҳо

Рӯйхат — ин якчанд қимат дар як тағйирёбанда:

```
бигзор шаҳрҳо = ["Душанбе", "Хуҷанд", "Кӯлоб"]

навис(шаҳрҳо)
навис("Шумора:", дарозӣ(шаҳрҳо))
навис("Якум:", шаҳрҳо[0])
```

**Диққат:** ҳисоб аз **сифр** сар мешавад. Унсури якум `[0]` аст, дуюм `[1]`.

Иваз кардан ва илова кардан:

```
шаҳрҳо[0] = "Душанбе (пойтахт)"
илова(шаҳрҳо, "Бохтар")
навис(шаҳрҳо)
```

Гузаштан аз рӯйхат:

```
барои шаҳр аз шаҳрҳо:
    навис("-", шаҳр)
```

Функсияҳои муфид:

```
навис(тартиб(шаҳрҳо))          # бо алифбои тоҷикӣ
навис(баръакс(шаҳрҳо))
навис(ҷамъи([1, 2, 3]))
навис(калонтарин([3, 9, 2]))
навис(хурдтарин([3, 9, 2]))
навис(дорад(шаҳрҳо, "Кӯлоб"))
```

Функсияи `тартиб` номҳоро бо **алифбои тоҷикӣ** ҷобаҷо мекунад. Ин муҳим
аст: дар аксари забонҳои дигар ҳарфҳои `ғ ӣ қ ӯ ҳ ҷ` баъд аз ҳарфи `я`
меоянд, ва рӯйхати синф нодуруст тартиб дода мешавад. Дар TajikLang
«Ғафуров» пеш аз «Яқубов» меистад, чунон ки бояд бошад.

**Машқ 8.**
1. Рӯйхати 5 рақам созед ва ҷамъ, миёна, калонтарин ва хурдтаринро чоп
   кунед.
2. Номҳои ҳамсинфонатонро дар рӯйхат нависед ва бо `тартиб` ҷобаҷо кунед.
3. Функсияе нависед, ки рӯйхат гирад ва танҳо рақамҳои ҷуфтро баргардонад.

## Дарси 9 — Луғатҳо ва матн

### Луғат

Луғат маълумотро бо **ном** нигоҳ медорад, на бо рақам:

```
бигзор донишҷӯ = {"ном": "Баҳром", "синф": 10, "баҳо": 5}

навис(донишҷӯ["ном"])
донишҷӯ["шаҳр"] = "Душанбе"

навис(калидҳо(донишҷӯ))
навис(қиматҳо(донишҷӯ))
навис(дорад(донишҷӯ, "шаҳр"))

барои калид аз донишҷӯ:
    навис(калид, "->", донишҷӯ[калид])
```

### Кор бо матн

Ҳамаи функсияҳои матнӣ **аз аввал дастрасанд** — ҳеҷ `ворид` лозим нест:

```
бигзор ҷумла = "  Донишҷӯёни Тоҷикистон  "

навис(тоза(ҷумла))                      # холигиҳоро мебарорад
навис(калон("салом"))                   # САЛОМ
навис(хурд("САЛОМ"))                    # салом
навис(ҷудо("а,б,в", ","))               # ["а", "б", "в"]
навис(пайваст(["а", "б"], "-"))         # а-б
навис(иваз("салом", "с", "к"))          # калом
навис(буриш("Тоҷикистон", 0, 3))        # Тоҷи
навис(ёфтан("Душанбе", "шан"))          # 2
навис(сар_мешавад("Душанбе", "Ду"))     # рост
навис(такрор("=", 10))                  # ==========
навис(рақам_аст("16"))                  # рост
```

`ёфтан` агар чизе наёбад, `холӣ` бармегардонад:

```
агар ёфтан(ҷумла, "Хуҷанд") == холӣ:
    навис("наёфтам")
```

> **Эзоҳ.** Ҳамин функсияҳоро бо `ворид матн` низ истифода бурдан мумкин аст:
> `матн.калон("салом")`. Ин ҳамон як функсия аст — модул танҳо номи гурӯҳ.

**Машқ 9.**
1. Луғате созед, ки шаҳр ва шумораи аҳолиро нигоҳ дорад. Ҳамаро чоп кунед.
2. Ҷумларо пурсед ва шумораи калимаҳояшро ҳисоб кунед.
3. Номро пурсед ва онро баръакс чоп кунед (`баръакс`).

## Дарси 10 — Модулҳо ва лоиҳаи хурд

### Модулҳо

Модул — маҷмӯи функсияҳои тайёр. Онро бо **`ворид`** меоред:

Функсияҳои риёзӣ низ аз аввал дастрасанд: `реша`, `гирд`, `мутлақ`, `мин`,
`макс`, `тасодуфӣ`. Модули `риёзӣ` танҳо номи гурӯҳи ҳамон функсияҳост.

```
ворид риёзӣ

навис(риёзӣ.реша(144))          # 12
навис(риёзӣ.дараҷа(2, 10))      # 1024
навис(риёзӣ.мутлақ(-7))         # 7
навис(риёзӣ.гирд(3.14159, 2))   # 3.14
навис(риёзӣ.фарш(3.7))          # 3
навис(риёзӣ.сақф(3.2))          # 4
навис(риёзӣ.мин(3, 7), риёзӣ.макс(3, 7))
навис(риёзӣ.тасодуфӣ(1, 6))     # рақами тасодуфӣ
навис(риёзӣ.ПИ)
```

Шумо метавонед модули худро созед: файли `асбоб.tj` нависед ва дар барномаи
худ `ворид асбоб` гӯед. (Ин дар компютер кор мекунад; дар браузер танҳо
модулҳои тайёр дастрасанд.)

### Лоиҳаи хурд: бозии тахминкунӣ

```
ворид риёзӣ
ворид матн

бигзор пинҳон = риёзӣ.тасодуфӣ(1, 20)
бигзор кӯшишҳо = 0
бигзор ёфт = дурӯғ

навис("Ман рақамеро аз 1 то 20 фикр кардам.")

то_вақте не ёфт ва кӯшишҳо < 5:
    бигзор ҷавоб = матн.тоза(хонед("Тахмини шумо: "))
    кӯшишҳо = кӯшишҳо + 1

    агар не матн.рақам_аст(ҷавоб):
        навис("Ин рақам нест.")
    вагарна:
        бигзор тахмин = ба_рақам(ҷавоб)
        агар тахмин == пинҳон:
            навис("Офарин! Бо", кӯшишҳо, "кӯшиш ёфтед.")
            ёфт = рост
        вагарна агар тахмин < пинҳон:
            навис("Зиёдтар.")
        вагарна:
            навис("Камтар.")

агар не ёфт:
    навис("Кӯшишҳо тамом шуданд. Рақам", пинҳон, "буд.")
```

**Машқи ниҳоӣ.** Журнали баҳоҳо созед:

1. Номҳо ва баҳоҳои 5 донишҷӯро дар рӯйхати луғатҳо нигоҳ доред.
2. Функсияе нависед, ки миёнаи баҳоҳоро ҳисоб кунад.
3. Номҳоро бо `тартиб` ҷобаҷо кунед ва ҷадвал чоп кунед.
4. Миёнаи умумии синфро ҳисоб кунед.
5. Бигӯед, кӣ баҳои аз ҳама баланд дорад.

Мисоли тайёр дар `examples/журнал.tj` ҳаст — вале аввал худатон кӯшиш кунед.

## Дарси 11 — Идоракунии давр ва хатоҳо

### Аз давр баромадан

**`шикан`** даврро мебандад, **`давом`** ба такрори оянда мегузарад:

```
барои i аз 1 то 10:
    агар i > 3:
        шикан
    навис(i)                    # 1 2 3

барои i аз 1 то 5:
    агар i % 2 == 0:
        давом
    навис(i)                    # 1 3 5
```

`шикан` танҳо даври наздиктаринро мебандад. Дар давр набошад — хатои
синтаксис.

### Хатоҳоро гирифтан

То ҳол ҳар хато барномаро мебаст. Бо **`кӯшиш`** ва **`хато`** барнома
метавонад давом кунад:

```
кӯшиш:
    бигзор адад = ба_рақам(хонед("Рақам: "))
    навис("Дучандаш:", адад * 2)
хато паём:
    навис("Ин рақам нест:", паём)
```

Номи баъд аз `хато` (дар ин ҷо `паём`) матни хаторо нигоҳ медорад. Онро
навиштан ихтиёрист:

```
кӯшиш:
    навис(1 / 0)
хато:
    навис("чизе нашуд")
```

### Роҳи даъват дар хатогиҳо

Вақте хато дар дохили функсия рӯй медиҳад, забон роҳи расиданро нишон
медиҳад:

```
Роҳи даъват:
    дар функсияи "дарунӣ", даъват дар сатри 4
    дар функсияи "берунӣ", даъват дар сатри 5
```

### Тағйирёбандаро кӯтоҳ навиштан

```
бигзор ҳисоб = 0
ҳисоб += 1        # ба ҷои: ҳисоб = ҳисоб + 1
ҳисоб *= 2
```

Ҳамин тавр `-=`, `/=` ва `%=`.

### Аз охир шумурдан

```
бигзор р = [10, 20, 30]
навис(р[-1])      # 30 — охирин
навис(р[-2])      # 20
```

### Тартиб бо калид

Барои тартиб додани рӯйхати луғатҳо **`тартиб_бо`** -ро истифода баред:

```
функсия номи(д):
    баргардон д["ном"]

барои д аз тартиб_бо(донишҷӯён, номи):
    навис(д["ном"])
```

### Кор бо файл

Ин ягона қисми китобхонаест, ки `ворид` талаб мекунад:

```
ворид файл

агар файл.мавҷуд("номҳо.txt"):
    барои сатр аз файл.сатрҳо("номҳо.txt"):
        навис(сатр)

файл.навиштан("натиҷа.txt", "тамом")
```

**Машқ 11.**
1. Рақамҳоро аз корбар пурсед, то он даме ки «тамом» нависад (`шикан`).
2. Ҳамон барномаро бо `кӯшиш` муҳофизат кунед, то матни нодуруст барномаро
   набандад.
3. Рӯйхати донишҷӯёнро бо `тартиб_бо` аз рӯи баҳо ҷобаҷо кунед ва беҳтаринро
   бо `[-1]` ёбед.
4. Натиҷаро бо `файл.навиштан` дар файл нигоҳ доред.

Мисоли тайёр: `examples/санҷиш.tj`.

## Дарси 12 — Саҳифаи интернетӣ

Акнун барномаи шумо метавонад **саҳифаи интернетӣ** созад.

Саҳифа як дарахт аст: сарлавҳа, матн, ҷадвал, тугма. Дар TajikLang дарахтҳо
аллакай ҳастанд — пас ҳеҷ забони наве омӯхтан лозим нест.

```
ворид саҳифа

саҳифа.нависед(
    саҳифа.сарлавҳа("Салом Тоҷикистон!"),
    саҳифа.матн("Ин аввалин саҳифаи ман аст."),
    саҳифа.рӯйхат(["Душанбе", "Хуҷанд", "Кӯлоб"]),
)
```

Дар майдончаи браузер саҳифа фавран пайдо мешавад.

### Ҷадвал аз маълумот

```
бигзор донишҷӯён = [
    {"ном": "Аҳмадов", "баҳо": 5},
    {"ном": "Ғафуров", "баҳо": 4},
]

саҳифа.нависед(
    саҳифа.ҷадвал(донишҷӯён, ["ном", "баҳо"]),
)
```

### Тугма ва функсия

Тугма функсияи шуморо даъват мекунад:

```
функсия салом_гӯй():
    саҳифа.нависед(саҳифа.матн("Салом!"))

саҳифа.нависед(
    саҳифа.тугма("Пахш кунед", салом_гӯй),
)
```

### Ранг ва андоза

Услуб як луғат аст, бо номҳои тоҷикӣ:

```
саҳифа.нависед(
    саҳифа.услуб(
        саҳифа.сарлавҳа("Ранга"),
        {"ранг": "green", "андоза": 32, "ҷойгиршавӣ": "center"},
    ),
)
```

Номҳои дастрас: `ранг`, `замина`, `андоза`, `фосила`, `ҳошия`, `васеъӣ`,
`баландӣ`, `канор`, `гӯшаҳо`, `ҳарф`, `ғафсӣ`, `ҷойгиршавӣ`.

### Майдони воридкунӣ

```
функсия салом_деҳ():
    бигзор ном = саҳифа.қимат("ном")
    саҳифа.нависед(саҳифа.матн("Салом,", ном))

саҳифа.нависед(
    саҳифа.майдон("ном"),
    саҳифа.тугма("Салом гӯй", салом_деҳ),
)
```

### Саҳифаро дар файл нигоҳ доштан

Дар терминал (на дар браузер) саҳифаро ҳамчун файли HTML сохтан мумкин аст:

```
ворид саҳифа
ворид файл

бигзор матни_саҳифа = саҳифа.ҳамчун_матн(
    саҳифа.сарлавҳа("Саҳифаи ман"),
    саҳифа.матн("Бо TajikLang сохта шуд."),
)

файл.навиштан("саҳифа.html", матни_саҳифа)
```

Баъд файли `саҳифа.html` -ро дар браузер кушоед — ин саҳифаи ҳақиқист.

**Машқ 12.**
1. Саҳифае созед, ки номи шумо, шаҳри шумо ва рӯйхати дӯстонатонро нишон
   диҳад.
2. Ҷадвали баҳоҳои худро созед ва бо `тартиб_бо` ҷобаҷо кунед.
3. Тугмае илова кунед, ки миёнаи баҳоҳоро ҳисоб карда нишон диҳад.
4. Саҳифаро бо `файл.навиштан` нигоҳ доред ва дар браузер кушоед.

Мисоли тайёр: `examples/саҳифа_демо.tj`.

## Дарси 13 — Қолибҳо ва абзорҳои пуртаъсир

### Қолиб (синф)

Қолиб маълумот ва амалҳоро якҷоя нигоҳ медорад. Мисли қолиби хишт: аз як
қолиб чандин объект сохта мешавад.

```
қолиб Донишҷӯ:
    функсия оғоз(худ, ном, баҳо):
        худ.ном = ном
        худ.баҳо = баҳо

    функсия хулоса(худ):
        агар худ.баҳо >= 4.5:
            баргардон "аъло"
        баргардон "хуб"

бигзор д = Донишҷӯ("Аҳмадов", 4.75)
навис(д.ном)
навис(д.хулоса())
```

- `оғоз` ҳангоми сохтани объект иҷро мешавад;
- `худ` худи объектро ифода мекунад — он параметри якум аст, вале ҳангоми
  даъват онро худи забон мегузорад, барои ҳамин `д.хулоса()` бе аргумент аст;
- дар дохили қолиб танҳо функсияҳо навишта мешаванд.

**Эзоҳ:** калимаи калидӣ `қолиб` аст, на `синф` — то шумо тавонед
`бигзор синф = 10` нависед.

### Мерос

```
қолиб Одам:
    функсия оғоз(худ, ном):
        худ.ном = ном
    функсия салом(худ):
        баргардон "Салом, " + худ.ном

қолиб Донишҷӯ мерос Одам:
    функсия оғоз(худ, ном, синф):
        худ.ном = ном
        худ.синф = синф

навис(Донишҷӯ("Ғафуров", 10).салом())
```

`Донишҷӯ` функсияи `салом` -ро аз `Одам` мегирад.

### чаро — «чаро тағйирёбандаи ман ҳамин аст?»

```
бигзор ҷамъ = 0
барои i аз 1 то 3:
    ҷамъ += i
чаро(ҷамъ)
```
```
Тағйирёбандаи "ҷамъ":
    сатри 1    →  0    (эълон)
    сатри 3    →  1    (ивазкунӣ)
    сатри 3    →  3    (ивазкунӣ)
    сатри 3    →  6    (ивазкунӣ)
```

Ин саволест, ки ҳар навомӯз медиҳад — ва дигар забонҳо ба он ҷавоб намедиҳанд.

### |> — амалҳо аз чап ба рост

Дар забони тоҷикӣ феъл дар охир меояд: «номҳоро тартиб деҳ ва чоп кун».
Аломати `|>` ҳамин тартибро медиҳад:

```
номҳо |> тартиб |> навис
"а,б,в" |> ҷудо(",") |> дарозӣ |> навис
```

Ин ҳамон чизест, ки `навис(дарозӣ(ҷудо("а,б,в", ",")))` — вале аз чап ба рост
хонда мешавад.

### Хатоҳои навъдор

```
кӯшиш:
    бигзор n = ба_рақам(хонед("Рақам: "))
    навис(100 / n)
хато "тақсим_ба_сифр":
    навис("Сифр нашавад.")
хато паём:
    навис("Хатои дигар:", паём)
```

Навъҳо: `тақсим_ба_сифр`, `номи_номаълум`, `навъи_нодуруст`,
`берун_аз_ҳудуд`, `калиди_нест`, `шумораи_аргумент`, `хатои_питон`,
`хатои_файл`. Блоки бе навъ ҳамаашро мегирад ва бояд охирин бошад.

**Машқ 13.**
1. Қолиби `Китоб` созед (ном, муаллиф, сол) ва функсияи `тавсиф` илова кунед.
2. Қолиби `Дарсӣ мерос Китоб` созед, ки фанро низ нигоҳ дорад.
3. Рӯйхати китобҳоро бо `тартиб_бо` аз рӯи сол ҷобаҷо кунед.
4. Барномаеро, ки хато медиҳад, бо `чаро` таҳлил кунед.

Мисолҳои тайёр: `examples/қолиб.tj` ва `examples/чаро_ва_қувват.tj`.
