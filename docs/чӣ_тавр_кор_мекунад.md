# Забон дар дохил чӣ тавр кор мекунад

Ин ҳуҷҷат барои онҳоест, ки даҳ дарсро тамом кардаанд ва мехоҳанд бидонанд:
вақте ки шумо тугмаи «Иҷро» -ро пахш мекунед, чӣ рӯй медиҳад?

Барнома аз чор марҳила мегузарад:

```
Матни барнома (.tj)
      ↓  лексер      — ҳарфҳо → токенҳо
   Токенҳо
      ↓  парсер      — токенҳо → дарахт
   Дарахти синтаксисӣ
      ↓  интерпретатор — дарахтро иҷро мекунад
   Натиҷа
```

Ҳар марҳиларо худатон дидан мумкин аст:

```
tajik --tokens examples/шарт.tj
tajik --ast examples/шарт.tj
```

---

## 1. Лексер — ҳарфҳо ба токенҳо табдил меёбанд

Лексер матнро аз чап ба рост мехонад ва танҳо як савол медиҳад: **дар ин ҷо
чӣ сар мешавад?** Ҳарф — ном сар мешавад. Рақам — адад. Нохунак — матн.

Лексер намедонад, ки барнома чӣ маъно дорад. Ӯ танҳо шаклҳоро мешиносад.

```
навис("Салом")
```

табдил меёбад ба:

```
IDENT('навис')@1:1
LPAREN('(')@1:6
STRING('Салом')@1:7
RPAREN(')')@1:14
NEWLINE@1:15
EOF@2:1
```

`@1:1` маънои «сатри 1, сутуни 1» -ро дорад. Ҳар токен ҷои худро дар бар
мегирад — маҳз барои ҳамин хатогиҳо метавонанд аломати `^` -ро дар ҷои
дуруст гузоранд.

### Ду чизи хоси тоҷикӣ

**Якум: муттаҳидсозии Unicode (NFC).** Ҳарфи `ӣ` -ро бо ду роҳ навиштан
мумкин аст: як рамз (U+04E3), ё `и` бо аломати болои он (U+0438 U+0304). Дар
экран онҳо якхелаанд, вале барои компютер — ду чизи гуногун.

Агар лексер инро ислоҳ намекард, `мебошӣ` -и навишташуда дар як клавиатура
ва `мебошӣ` -и навишташуда дар клавиатураи дигар **ду тағйирёбандаи гуногун**
мешуданд. Ҳеҷ кас ҳеҷ гоҳ намефаҳмид, ки чаро барнома кор намекунад.

Лексер аввал тамоми файлро ба шакли NFC табдил медиҳад. Як сатри код — ва
масъала нест.

**Дуюм: номҳои тоҷикӣ.** Дар Python функсияи `isalpha()` барои `ҳ`, `қ`, `ӯ`
низ «рост» медиҳад. Барои ҳамин `ҳарорат`, `шаҳр`, `қимат` бидуни ҳеҷ кори
иловагӣ кор мекунанд.

### Токенҳое, ки дар матн нестанд

Фосилагузорӣ масъалаи махсус дорад: **чизе, ки лозим аст, ҳарф нест**. Калимаи
`навис` бо ҳарфҳои «навис» навишта мешавад, вале «дар ин ҷо блок сар мешавад»
бо **набудани** чизе дар сатри оянда навишта мешавад.

Барои ҳамин лексер ду токени навро **месозад**, ки дар матн вуҷуд надоранд:

```
агар x > 5:                IF IDENT GT NUMBER COLON NEWLINE
    навис("калон")         INDENT IDENT LPAREN STRING RPAREN NEWLINE
навис("тамом")             DEDENT IDENT ...
```

Тамоми механизм — як рӯйхат:

```python
self.indents = [0]     # паҳноии ҳар блоки кушода
```

Агар сатр чуқуртар бошад — `INDENT`. Агар камтар — `DEDENT` барои ҳар сатҳи
пӯшидашуда. Дар охири файл ҳама пӯшида мешаванд.

Се қоида, ки ҳар кадом аз Python сахттаранд:

- **танҳо холигӣ, tab не** — файле, ки tab ва холигиро омехта мекунад,
  метавонад дуруст намояд ва нодуруст кор кунад;
- **маҳз 4 холигӣ** — на «ҳар чӣ, факат якхела». Як қоида — як таълим;
- **дедент бояд ба сатҳи кушода мувофиқ бошад.**

Як истисно: дохили қавсҳои `(`, `[`, `{` фосила ва сатри нав маънӣ надоранд.
Бе ин ҷадвали маълумотро дар як сатри дароз навиштан лозим меомад.

## 2. Парсер — токенҳо ба дарахт табдил меёбанд

Рӯйхати токенҳо ҳамвор аст, вале маънӣ дар сохтор аст. `навис("Салом")` чор
чизи паси ҳам нест — ин **як даъват** аст, ки номаш `навис` ва аргументаш
матн аст:

```
Program
  └── ExpressionStatement
        └── CallExpression
              ├── callee: Identifier('навис')
              └── arguments: [StringLiteral('Салом')]
```

Парсери мо **рекурсивӣ-фуроянда** аст: барои ҳар қоидаи грамматика як метод,
ва методҳо якдигарро ҳамон тавр даъват мекунанд, ки қоидаҳо дохили ҳам
ҷойгиранд.

### Тартиби амалҳо дар шакли дарахт аст

Интерпретатор дар бораи тартиби амалҳо **ҳеҷ чиз намедонад**. Ба дарахти
`2 + 3 * 4` нигаред:

```
BinaryOp('+')
  ├── NumberLiteral(2)
  └── BinaryOp('*')        ← чуқуртар, пас аввал ҳисоб мешавад
        ├── NumberLiteral(3)
        └── NumberLiteral(4)
```

Ин аз ду қоида баромад:

```
term    ::= factor { ("+" | "-") factor }
factor  ::= unary  { ("*" | "/" | "%") unary }
```

`term` тавассути `factor` навишта шудааст. Пас `_term()` аввал `_factor()`
-ро даъват мекунад, `_factor()` тамоми `3 * 4` -ро мегирад, ва танҳо баъд
`_term()` аломати `+` -ро мебинад.

Занҷири пурра:

```
ё  <  ва  <  не  <  муқоиса  <  + -  <  * / %  <  -x  <  даъват
```

Барои илова кардани сатҳи нав як қоида илова мешавад — ҷадвали тартиб вуҷуд
надорад.

Ҳалқаи `{ }` дар ҳар қоида боис мешавад, ки амалҳо аз чап ба рост ҳисоб
шаванд: `10 - 3 - 2` ин `(10 - 3) - 2` аст, яъне 5, на 9.

Барои муқоиса ба ҷои `{ }` аломати `[ ]` истифода шудааст — «на бештар аз
як». Барои ҳамин `1 < 2 < 3` хатои синтаксис аст. Дар Python ин маънои
`1 < 2 ва 2 < 3` -ро дорад, дар C бошад маънои дигар. Мо ҳеҷ кадомро иҷозат
намедиҳем, то касе фиреб нахӯрад.

## 3. Дарахт — шакли барнома

Дарахт сарҳади байни «чӣ навишта шуд» ва «чӣ бояд шавад» аст. Баъд аз ин
нуқта ҳеҷ кас ба матн барнамегардад.

Барои ҳамин илова кардани амали нав маънои илова кардани як навъи нави гиреҳ
ва як шохаи нав дар `execute` -ро дорад — на аз нав навиштани ҳама чиз.

Ду гиреҳ махсусан ҷолибанд:

**`LogicalOp` аз `BinaryOp` фарқ мекунад.** `2 + 3` ва `рост ва дурӯғ` як
шакл доранд. Вале `BinaryOp` ҳамеша ҳарду тарафро ҳисоб мекунад, ва
`LogicalOp` метавонад танҳо якеро ҳисоб кунад:

```python
if node.operator == "ва" and not left:
    return False          # тарафи рост ҳисоб намешавад
```

Барои ҳамин `дурӯғ ва 1 / 0 == 1` натиҷаи `дурӯғ` медиҳад, на хатои тақсим
ба сифр.

**`вагарна агар` гиреҳи худро надорад.** Ин танҳо як `IfStatement` аст, ки
дохили шохаи `вагарна`-и дигаре нишастааст.

## 4. Интерпретатор — дарахт иҷро мешавад

Интерпретатори мо **дарахтгард** аст: ҳар гиреҳро мебинад ва фавран ҳисоб
мекунад. Ин сусттарин усул ва равшантарин усул аст — барои забони таълимӣ
маҳз ҳамин лозим.

### Соҳаҳо — як синф ва як нишондиҳанда

```python
class Environment:
    def __init__(self, parent=None, is_function_scope=False): ...
```

Ҳар блок ва ҳар даъвати функсия яктоашро месозад, ки ба соҳаи берунӣ пайваст
аст. Ҷустуҷӯ ба берун меравад; `бигзор` ҳамеша дар соҳаи ҷорӣ эълон мекунад.

Аз ҳамин як сохтор се натиҷа мебарояд:

**Ҳар такрори давр соҳаи нав мегирад** — барои ҳамин `бигзор` дохили давр дар
ҳар такрор кор мекунад.

**Closure — ин соҳаест, ки функсия дар он эълон шудааст:**

```python
scope = Environment(function.closure, is_function_scope=True)
```

`function.closure`, на соҳаи даъваткунанда. Маҳз ҳамин як калима боис
мешавад, ки функсия ҳамеша номҳои атрофи матни худро бинад.

**`is_function_scope` нишон медиҳад, ки қоидаи «пинҳон накардан» дар куҷо
меистад.** Блок набояд тағйирёбандаи ҳамсояро пинҳон кунад; вале функсия
бояд озод бошад, ки тағйирёбандаҳои худро чӣ тавр хоҳад ном гузорад.

### `баргардон` истисно мепартояд

Интерпретатор `баргардон` -ро дар чуқурии даъватҳои дохили ҳам иҷро мекунад,
ва роҳи дигаре нест, ки қиматро ба боло баргардонад:

```python
class ReturnSignal(Exception):
    def __init__(self, value): self.value = value
```

Ин хато нест — ин сигнали идоракунӣ аст. Ғайр аз `_call_function` касе онро
намегирад.

### Ҳадҳое, ки ба ҷои овезон мондан дарс медиҳанд

```python
MAX_ITERATIONS = 1_000_000
MAX_CALL_DEPTH = 200
```

Давре, ки хотима надорад, хатогии тоҷикӣ мегирад. Рекурсияи беохир хатогие
мегирад, ки мегӯяд функсияи рекурсивӣ ҳолати хотима лозим дорад.

Браузери овезонмонда ба касе чизе намеомӯзад.

1. Файле нависед, ки танҳо `агар x:` дошта бошад. Лексер чӣ мебарорад? Кадом
   қисм хато медиҳад — лексер, парсер ё интерпретатор?
2. Дарахти `-2 * 3 + 4` -ро дар коғаз кашед, баъд бо `--ast` санҷед.
3. Функсияи рекурсивии `фибоначчи(n)` нависед. Аз кадом `n` сар карда суст
   мешавад ва чаро? (Ин ҷавоби ҳақиқӣ ба саволи «кай интерпретатори
   дарахтгард намерасад» аст.)
4. Оператори `**` (тавон) илова кунед. Он бояд аз `*` сахттар пайваст шавад
   ва аз рост ба чап ҳисоб шавад: `2 ** 3 ** 2` ин 512 аст, на 64.
5. Калимаи `шикан` -ро илова кунед. Шумо токен, гиреҳ, синфи сигнал (мисли
   `ReturnSignal`) ва `try` дар се методи давр лозим доред.
