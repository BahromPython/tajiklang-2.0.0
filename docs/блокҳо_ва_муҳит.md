# TajikBlocks, localhost ва муҳити лоиҳа

TajikLang акнун се роҳи кор дорад, вале ҳамаи онҳо як забонро истифода мебаранд:

| Чиз | Барои чӣ |
|---|---|
| `tajik блокҳо` | омӯхтани рамз бо блокҳои визуалӣ |
| `tajik пешнамоиш` | дидани сомонаи TajikWeb дар localhost |
| `tajik лоиҳа нав` | сохтани лоиҳае, ки китобхонаҳои худашро дорад |

Ҳеҷ кадоми инҳо Python, pip, Node.js ё аккаунт намехоҳанд, агар TajikLang-ро
бо installer-и Windows насб карда бошед.

## TajikBlocks

```powershell
tajik блокҳо
```

Браузер саҳифаи маҳаллиро мекушояд. Дар тарафи рост блокҳоро интихоб кунед:
`Навис`, `Тағйирёбанда`, `Агар`, `Давр` ё `Рамзи ман`.

Ҳар блок рамзи ҳақиқии TajikLang месозад. Масалан, блоки **Навис** инро месозад:

```tajik
навис("Салом Тоҷикистон!")
```

Тугмаи **Иҷро** ҳамон рамзро бо муҳаррики TajikLang дар компютери худатон
иҷро мекунад. Сервер танҳо ба `127.0.0.1` гӯш мекунад — яъне ягон кас аз
интернет ба он пайваст шуда наметавонад.

Блокҳо оғози хуб ҳастанд, на маҳдудият: метавонед рамзро дар панели TajikLang
дастӣ иваз, нусха ё ба муҳаррир гузаронед.

## Сомона дар localhost

Дар дохили лоиҳаи TajikWeb:

```powershell
tajik пешнамоиш
```

Ин аввал `index.tj`-ро ба HTML месозад, баъд онро дар суроғаи маҳаллӣ ба мисли
`http://127.0.0.1:8000/` мекушояд. Барои қатъ кардан дар терминал `Ctrl+C`
пахш кунед. Барои нашри оммавӣ ҳамоно `tajik веб омода-github` истифода баред.

## Муҳити худи лоиҳа

```powershell
tajik лоиҳа нав рӯзномаи_синф
cd рӯзномаи_синф
tajik барнома.tj
```

Лоиҳа чунин шакл дорад:

```text
рӯзномаи_синф/
├── барнома.tj
└── .tajiklang/
    ├── лоиҳа.json
    └── китобхона/
```

Барои насб кардани китобхона фақат ба ҳамин лоиҳа:

```powershell
tajik гирифтан --лоиҳа омор
```

Баъд дар `барнома.tj`:

```tajik
ворид омор
навис(омор.медиана([3, 4, 5]))
```

TajikLang аввал файли ҳамсояро меҷӯяд, баъд китобхонаи маҳаллии ҳамин лоиҳаро
ва баъд китобхонаи умумиро. Ҳамин тавр ҳар лоиҳа версияи худашро нигоҳ дошта
метавонад, бе он ки ба лоиҳаи дигар таъсир расонад.

Агар папкаи кӯҳна доред, ба он муҳит илова кунед:

```powershell
tajik муҳит соз
```
