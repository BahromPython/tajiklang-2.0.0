# TajikWeb — сомона бо TajikLang

**TajikWeb** роҳи осон барои сохтани сомонаи статикӣ аст: шумо саҳифаро бо
TajikLang менависед ва фармони `tajik веб соз` як `index.html`-и оддӣ месозад.
Он HTML-ро GitHub Pages, Netlify ё дилхоҳ хостинги статикӣ мекушояд.

Версияи аввал барои сомонаҳои мазмунӣ сохта шудааст: портфолио, саҳифаи синф,
ҳуҷҷатҳо, эълон, рӯзнома ё лоиҳаи мактабӣ. Барои барномаи интерактивии калон
қабати баъдӣ меояд; ҳоло тугмаҳои дорои функсия танҳо дар playground кор
мекунанд, зеро HTML-и статикӣ ягон сервер ё муҳаррики пинҳонӣ надорад.

## Оғоз

```powershell
tajik веб нав сомонаи_ман
cd сомонаи_ман
tajik веб соз
```

Ин чор чизро мебинед:

| Файл ё папка | Кор |
|---|---|
| `index.tj` | рамзи сомонаи шумо |
| `static/` | расм, PDF, CSS ё файлҳои дигар |
| `tajikweb.json` | маълумоти хурди лоиҳа |
| `нашр/index.html` | сомонаи омода барои нашр |

`index.tj` аллакай мисоли хурд дорад. Онро тағйир диҳед ва боз `tajik веб соз`
нависед.

## Мисоли як саҳифа

```tajik
ворид саҳифа

саҳифа.нависед(
    саҳифа.қуттӣ(
        саҳифа.сарлавҳа("Портфолиои Баҳром", {"ранг": "#0b4f6c", "андоза": 34}),
        саҳифа.матн("Ман бо TajikLang барнома месозам."),
        саҳифа.сарлавҳа("Лоиҳаҳо", 2),
        саҳифа.рӯйхат(["TajikLang", "Сомонаи синф", "Бозии ман"]),
        саҳифа.расм("static/акс.png", "Акси ман"),
    ),
)
```

Унсурҳои асосӣ:

| Фармон | Натиҷа |
|---|---|
| `саҳифа.сарлавҳа("...")` | сарлавҳа |
| `саҳифа.матн("...")` | параграф |
| `саҳифа.рӯйхат([...])` | рӯйхат |
| `саҳифа.ҷадвал(сатрҳо, сарлавҳаҳо)` | ҷадвал |
| `саҳифа.қуттӣ(...)` | як гурӯҳи унсурҳо |
| `саҳифа.қатор(...)` | унсурҳо паҳлӯи ҳам |
| `саҳифа.расм("static/акс.png", "тавсиф")` | расм |
| `саҳифа.услуб(унсур, {...})` | ранг, фосила ва услуб |

Номҳои маъмули услуб тоҷикӣ ҳастанд: `ранг`, `замина`, `андоза`, `фосила`,
`ҳошия`, `васеъӣ`, `баландӣ`, `канор`, `гӯшаҳо`, `ҳарф`, `ғафсӣ` ва
`ҷойгиршавӣ`. Касе, ки CSS медонад, метавонад номи CSS-ро ҳам истифода барад.

## Нашр дар GitHub Pages

Дар дохили папкаи сомона ин фармонро иҷро кунед:

```powershell
tajik веб омода-github
```

Он файли `.github/workflows/tajikweb-pages.yml` месозад. Баъд:

1. Папкаи сомонаро ҳамчун repository-и GitHub созед ё ба repository-и мавҷуда
   гузоред.
2. Файлҳоро commit ва push кунед.
3. Дар GitHub: **Settings → Pages → Source → GitHub Actions**-ро интихоб кунед.
4. Дар ҷадвали **Actions** кори «Нашри TajikWeb»-ро интизор шавед. Баъд аз анҷом
   GitHub суроғаи сомонаро нишон медиҳад.

Ҳар `push`-и баъдӣ сомонаро аз нав месозад ва нашр мекунад. Ин муҳим аст:
`нашр/` маҳсулоти сохташуда аст, вале манбаи ҳақиқӣ ҳамеша `index.tj` мебошад.

## Маҳдудияти ҳозира

Сомонаи сохташуда static аст. Матн, расм, рӯйхат, ҷадвал ва услуб пурра кор
мекунанд. `саҳифа.тугма(..., функсия)` барои playground-и браузер аст; он ҳанӯз
ба HTML-и static табдил намеёбад. Қадами баъдӣ **TajikWeb App** мешавад: саҳифаи
интерактивӣ, ки функсияҳои TajikLang-ро дар браузер иҷро мекунад.
