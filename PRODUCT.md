# TajikLang

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Users

Tajik-speaking school and university students learning programming, plus more
advanced learners who need a practical Tajik-first development environment.

## Product Purpose

TajikLang makes programming concepts and error messages accessible in Tajik,
while producing skills that transfer to mainstream languages. TajikLang Studio
is the installed, no-Python-required workspace for writing and running projects.

## Positioning

The product combines a Tajik programming language, Tajik-language diagnostics,
TajikBlocks, project tools, and a native desktop Studio rather than merely
translating Python keywords.

## Operating Context

Students install a normal desktop application on Windows, macOS, or Linux;
open a project; write `.tj` files; run with F5; check mistakes with F6; and
read output and beginner-friendly errors without using a terminal.

## Capabilities and Constraints

The Studio is a Tkinter desktop application packaged with PyInstaller. It must
remain fast, keyboard-friendly, Unicode-safe for Tajik Cyrillic, readable on
school computers, and usable without a Python installation.

## Brand Commitments

The product name is TajikLang Studio. The user requested a familiar professional
IDE structure comparable to VS Code, with only restrained references to Tajik
identity: a deep indigo workbench, a turquoise/green Tajik accent, and the
TajikLang “Т” mark. It must not copy another product's logo, artwork, or brand.

## Evidence on Hand

The repository contains the working interpreter, TajikBlocks, examples,
documentation, packaging scripts, release automation, and the existing Studio
implementation at `tajiklang/ide.py`. No external customer testimonials,
certifications, or commercial claims should be invented.

## Product Principles

- The common path—open, write, run, understand—must be visible immediately.
- Familiar editor conventions reduce learning friction.
- Tajik language and diagnostics belong in the product, not merely in marketing.
- Advanced tools are available without cluttering a beginner's first screen.

## Accessibility & Inclusion

Maintain strong contrast, keyboard shortcuts, readable system typography, and
clear Tajik labels. Do not rely only on color to communicate runtime state.
