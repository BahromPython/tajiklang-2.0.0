# TajikLang барои VS Code

Ранга кардани синтаксиси файлҳои `.tj`.

## Насб (маҳаллӣ)

Ин ҷузвдонро ба ҷузвдони васеъкуниҳои VS Code нусхабардорӣ кунед:

- Windows: `%USERPROFILE%\.vscode\extensions\tajiklang`
- macOS / Linux: `~/.vscode/extensions/tajiklang`

Баъд VS Code -ро аз нав кушоед ва файли `.tj` -ро боз кунед.

## Чӣ ранга мешавад

- калимаҳои калидӣ: `бигзор`, `агар`, `вагарна`, `барои`, `то_вақте`,
  `функсия`, `баргардон`, `ворид`;
- қиматҳо: `рост`, `дурӯғ`, `холӣ`;
- функсияҳои тайёр: `навис`, `хонед`, `дарозӣ` ва ғайра;
- матн, рақам ва шарҳҳо;
- калимаҳои захирашуда (`шикан`, `давом`, `синф`, `кӯшиш`, `хато`) ҳамчун
  хато нишон дода мешаванд — онҳо ҳанӯз кор намекунанд.

## Барои таҳиягарон / A note for maintainers

Сарҳади калимаҳо бо `\p{L}\p{N}_` навишта шудааст, на бо `\w`.

TextMate от Oniguruma истифода мебарад, ки дар он `\w` танҳо ҳарфҳои лотиниро
дар бар мегирад. Бо `\w` калимаи `тоза` ҳамчун калимаи калидии `то` ранга
мешуд, ва `хатогӣ` ҳамчун хато нишон дода мешуд. Онро иваз накунед.
