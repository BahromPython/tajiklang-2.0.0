# TajikLang барои Visual Studio Code

Навиштани барномаҳои `.tj` бо ранга кардани синтаксис барои **TajikLang** —
забони барномасозӣ бо калимаҳо ва хатогиҳои тоҷикӣ.

![TajikLang](assets/tajiklang.png)

## Чӣ медиҳад

- Ранг барои TajikLang Next: `дода`, `тағйир`, `нишон`, `дигар` ва блокҳои
  `{ ... }`.
- Ранг барои синтаксиси классикӣ: `бигзор`, `агар`, `вагарна`, `барои`,
  `функсия`, `ворид` ва ғайра.
- Фарқ кардани матн, рақам, шарҳ, операторҳо, функсияҳо ва номҳои қолиб.
- Қавсҳои мувофиқ ва шарҳи сатрӣ бо `#`.
- Дастгирии номҳо бо ҳарфҳои тоҷикӣ: `шаҳр`, `ҳарорат`, `қимат`, `Баҳром`.

## Насб

1. Файли `tajiklang-3.0.4.vsix`-ро аз саҳифаи
   [TajikLang Releases](https://github.com/BahromPython/tajiklang-2.0.0/releases)
   гиред.
2. Дар VS Code ба **Extensions** гузаред.
3. Тугмаи `…` → **Install from VSIX…**-ро интихоб кунед.
4. Файлро интихоб карда, VS Code-ро аз нав кушоед.

Ё аз терминал:

```text
code --install-extension tajiklang-3.0.4.vsix
```

## Барномаи намунавӣ

```tj
дода ном <- "Баҳром"
дода синну <- 16

агар синну >= 16 {
    нишон "Салом", ном
} дигар {
    нишон "Омӯзишро идома диҳед"
}
```

## Иҷрои барнома

Ин васеъкунӣ барои ранга кардани рамз аст. Барои иҷро кардан **TajikLang
Studio**-ро истифода баред ё дар Command Prompt / PowerShell нависед:

```text
tajik барномаи_ман.tj
```

Барои роҳнамо ва боргирии Studio: [tajiklang.netlify.app](https://tajiklang.netlify.app).
