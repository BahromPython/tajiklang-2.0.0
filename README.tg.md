# TajikLang — забони барномасозӣ бо забони тоҷикӣ

> Барномасозиро барои хонандагони тоҷикзабон дастрас кардан — то онҳо
> мафҳумҳои барномасозиро бо забони модарии худ омӯзанд.

Ҳамаи калимаҳои калидӣ, ҳамаи хатогиҳо ва ҳатто тартиби алифбо бо забони
тоҷикӣ.

```
ворид риёзӣ

бигзор донишҷӯён = [
    {"ном": "Яқубов", "баҳоҳо": [5, 4, 5, 5]},
    {"ном": "Ғафуров", "баҳоҳо": [3, 4, 4, 3]},
]

функсия миёна(баҳоҳо):
    бигзор ҷамъ = 0
    барои б аз баҳоҳо:
        ҷамъ = ҷамъ + б
    баргардон ҷамъ / дарозӣ(баҳоҳо)

барои д аз донишҷӯён:
    бигзор натиҷа = миёна(д["баҳоҳо"])
    агар натиҷа >= 4.5:
        навис(д["ном"], "— аъло")
    вагарна:
        навис(д["ном"], "—", риёзӣ.гирд(натиҷа, 2))
```

## Барои муаллимон

Файли `docs/ТАРҶУМА.md` рӯйхати ҳамаи матнҳоест, ки забон ба донишҷӯ
нишон медиҳад. Агар шумо тоҷикзабон бошед ва 20 дақиқа вақт дошта бошед,
онро хонед ва ҷумлаҳои носуфтаро ислоҳ кунед. Ин муфидтарин кӯмакест, ки ба
ин лоиҳа расонида метавонед — муаллифи он тоҷикзабон нест.

## Чаро ин танҳо «Python бо калимаҳои тоҷикӣ» нест

- **Муттаҳидсозии Unicode.** Ҳарфи `ӣ` ду шакли навишт дорад, ки дар экран
  якхелаанд. Бе ислоҳ як ном ду тағйирёбанда мешуд.
- **Тартиби алифбои тоҷикӣ.** Дар Unicode ҳарфҳои `ғ ӣ қ ӯ ҳ ҷ` баъд аз `я`
  меоянд, бинобар ин ҳар забони дигар рӯйхати синфро нодуруст тартиб медиҳад.
  Дар TajikLang «Ғафуров» пеш аз «Яқубов» меистад.
- **Ҳеҷ гуна ҷодугарӣ нест.** Дар TajikLang `агар ном:` хато аст —
  `агар ном != "":` нависед. Ҳар қоида равшан аст.
- **Хатогиҳо таълим медиҳанд.** Ҳар хатогӣ сатр, сутун, аломати `^` ва
  маслиҳат дорад — ва роҳи даъватро нишон медиҳад.
- **Барнома пеш аз иҷро санҷида мешавад.** Хатогиҳо пеш аз он ки чизе чоп
  шавад, ҳамаашон якбора нишон дода мешаванд. Python инро карда наметавонад.
- **Ҳисоби даҳӣ.** `0.1 + 0.2` дар TajikLang маҳз `0.3` аст. Дар Python,
  C, Java ва JavaScript — не.
- **Саҳифаи интернетӣ.** Бо `ворид саҳифа` барномаи шумо саҳифаи ҳақиқӣ
  месозад — дар браузер зинда, ё ҳамчун файли HTML.

Ин забон бо забони Python **навишта шудааст**, вале ба Python **табдил
намеёбад**. Ин ду чизи гуногун аст — тафсилот дар `LANGUAGE_SPEC.md`.
