# худсоз — TajikLang, навишташуда бо TajikLang

*(TajikLang written in TajikLang — the self-hosting compiler.)*

Ин ҷузвдон ба як савол ҷавоб медиҳад: **оё TajikLang воқеан як забон аст, ё
танҳо як барномаи Python?**

Ҷавоб дар се файл аст:

| файл | чӣ кор мекунад |
|---|---|
| [`лексер.tj`](лексер.tj) | матни барномаро ба токенҳо тақсим мекунад |
| [`тарҷумон.tj`](тарҷумон.tj) | токенҳоро мехонад ва JavaScript менависад |
| [`худсозӣ.tj`](худсозӣ.tj) | ҳар се файли болоиро тарҷума мекунад |

Ҳар се **бо худи TajikLang** навишта шудаанд. Дар ин ҷузвдон ягон сатри Python
нест.

---

## Санҷиши нуқтаи собит

Худсозӣ (bootstrapping) як даъвои калон аст, бинобар ин онро санҷидан лозим
аст. Санҷиш се насл месозад:

```
насли 0    тарҷумони асосӣ  →  лексер.js, тарҷумон.js, худсозӣ.js
насли 1    node худсозӣ.js  →  ҳамон се файл, аз нав
насли 2    node худсозӣ.js  →  ва боз як бор
```

Ду чиз бояд дуруст барояд:

**насли 1 == насли 2.** Тарҷумон нуқтаи собит дорад. Агар дар тарҷумон хатое
мебуд, ки натиҷаи худашро тағйир медод, гузариши дуюм аз якум фарқ мекард. Ин
санҷиши классикии худсозист.

**насли 0 == насли 1.** Ду татбиқи тамоман гуногун — яке дар Python, дигаре дар
JavaScript — ҳарф ба ҳарф як натиҷа медиҳанд. Барномаи санҷидашаванда худи
тарҷумон аст, пас ҳар ҷое ки лексери тоҷикӣ ва лексери асосӣ ихтилоф доранд,
ҳамчун фарқи байтҳо намоён мешавад.

Иҷро кардан:

```powershell
powershell -File худсоз\санҷиши_худсозӣ.ps1
```

ё ҳамчун қисми санҷишҳои умумӣ:

```bash
python -m unittest tests.test_bootstrap
```

### Ин санҷиш аллакай як хато ёфт

`лексер.tj` рамзи гурезии `\r`-ро намедонист ва онро ба ҳарфи оддии `r` табдил
медод. Натиҷа: дар `АЛОМАТҲО` як `r` пайдо шуд, яъне ҳарфи **r** ҷудокунанда
гардид — ва номи `ба_javascript` ба ду ном тақсим шуд: `ба_javasc` ва `ipt`.

Ҳеҷ санҷиши оддӣ инро намеёфт. Санҷиши нуқтаи собит онро дар ҳамон гузариши
аввал нишон дод, зеро барномаи санҷидашаванда худи тарҷумон буд.

## Се ваъдаи забон дар JavaScript

[`асос.js`](асос.js) ёрирасонҳоест, ки коди тарҷумашуда истифода мебарад. Кори
асосии он нигоҳ доштани маънои TajikLang дар муҳити бегона:

**Рақамҳо дақиқанд.** JavaScript танҳо рақами дуӣ дорад, ки `0.1 + 0.2` -ро
`0.30000000000000004` мекунад. Дар `асос.js` ҷамъ, тарҳ ва зарб бо адади
бутуни миқёсшуда иҷро мешаванд, пас `0.1 + 0.2 == 0.3` рост мемонад.

**Ҳеҷ чиз худ ба худ рост нест.** `__шарт()` танҳо `рост` ва `дурӯғ` қабул
мекунад. `агар 5:` дар ҳар ду муҳит хатост.

**Алифбои тоҷикӣ тартиби худро дорад.** `ғ` баъди `г` меояд, на баъди `я`.
Ҳамон калиди се-қисма, ки дар `collation.py` ҳаст, дар JavaScript такрор шуда
аст — ва ин низ як фарқро ошкор кард: тартиби аломатҳо нисбат ба ҳарфҳо
дар аввал мувофиқ набуд.

## Ҳоло чӣ дастгирӣ мешавад

**Ҳаст:** `бигзор`, додани қимат ва `+= -= *= /= %=`, `агар` / `вагарна агар` /
`вагарна`, `барои ... аз ... то ...`, `барои ... аз рӯйхат`, `то_вақте`,
`функсия` ва `баргардон`, `шикан`, `давом`, `ворид`, рӯйхат ва луғат, дастрасӣ
бо `[...]`, амалҳои арифметикӣ ва мантиқӣ, ва тақрибан 45 функсияи тайёр.

**Ҳанӯз нест:** `қолиб` ва `мерос` (синфҳо), `кӯшиш`/`хато`, оператори `|>`,
`чаро`, модулҳои `риёзӣ` / `матн` / `питон` / `саҳифа`, санҷиши пеш аз иҷро, ва
хатогиҳои иҷро бо рақами сатр.

Ин рӯйхати дуюм маънои онро дорад, ки тарҷумони асосӣ ҳанӯз татбиқи пурра аст.
Тарҷумони худсохт зермаҷмӯаеро дастгирӣ мекунад, ки барои навиштани худаш
кофист — ва ин маҳз ҳамон нуқтаест, ки ҳар забони худсоз аз он оғоз мекунад.

## Чаро JavaScript?

Барои он ки натиҷа дар браузер низ кор кунад. Ҳоло майдони машқ (playground)
6 МБ CPython-ро ба браузер бор мекунад; вақте ки тарҷумони худсохт пурра шавад,
ҳамон саҳифа метавонад танҳо чанд килобайт JavaScript бор кунад.

Роҳи дигар — тарҷума ба C — дар [`../examples/тарҷумон.tj`](../examples/тарҷумон.tj)
ҳамчун намунаи хурд ҳаст.
